# Strategy Docs

Thu muc nay tra loi cau hoi: "Tai sao microSchedule v2 chon cach nay?"

Pham vi:
- Quyet dinh kien truc va trade-off.
- Chinh sach data, migration, backup, permission, quality gate.
- Huong dan cho Tier 1/Tier 2 khi can ra quyet dinh moi.

Tai lieu hien co:
- `v2_architecture_strategy.md`
- `v2_data_migration_strategy.md`
- `v2_ui_strategy.md`
- `v2_ai_agent_strategy.md`

Nguyen tac bien soan:
- Neu tai lieu la "how-to", dat trong `docs/*_GUIDE.md`.
- Neu tai lieu la "why this design", dat trong `docs/strategy/`.
- Moi strategy can co: boi canh, quyet dinh, trade-off, tac dong, quality gates.
